# Where Is the Line?

An interactive companion to *Preserving the Nuclear Testing Moratorium in Turbulent Times* (Sanaa Alvira, VCDNP Japan Chair Fellowship 2026).

Live page: https://sanaaalv.github.io/nuclear-testing/

## What is in this folder

| File | What it is | Do I edit it? |
|---|---|---|
| `content.txt` | Every word on the page: intro, markers, key terms, quiz, sources | **Yes. This is the only file you need.** |
| `index.html` | The machinery: layout, scale, quiz logic | No |
| `castle-bravo.jpg` | The photo at the top | Only to swap the photo |

## How to make a change

1. Open `content.txt` on GitHub.
2. Click the pencil icon (top right of the file).
3. Change the words. To add something, copy a whole block (from its CAPITAL word down to the empty line), paste it, and edit it.
4. Scroll down and click **Commit changes**.
5. Wait one or two minutes, then refresh the live page.

The top of `content.txt` explains the format, including how to add italics, links and yields.

## If something breaks

The page shows a yellow note at the top naming the block it could not read. Fix that block and save again.

To undo a change: open `content.txt`, click **History**, open the earlier version, and copy its text back in.

## Swapping the photo

Upload the new image with **Add file → Upload files**, then change the `photo:` line in `content.txt` to the new file name.
